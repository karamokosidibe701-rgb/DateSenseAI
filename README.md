
# 🎂 DateSenseAI — Birthday Countdown

A simple and interactive web application that calculates how many days remain until your next birthday.

## 🌐 Live Demo

Try the application here:

**[Launch DateSenseAI](https://datesenseai.streamlit.app/)**

> If the link changes, replace it with the public URL shown by Streamlit.

## 📌 Project Overview

DateSenseAI allows users to enter their date of birth and discover:

- The number of days until their next birthday
- The exact date of their next birthday
- The day of the week
- The age they will reach

The application automatically calculates the next birthday based on the current date.

## 🛠️ Technologies Used

- **Python** — date calculations and application logic
- **Streamlit** — interactive web interface
- **GitHub** — source code management
- **Streamlit Community Cloud** — application deployment

## ⚙️ How It Works

1. The user selects their date of birth.
2. The application determines the next birthday.
3. Python calculates the number of remaining days.
4. The result is displayed in an interactive interface.

The application also handles birthdays on February 29.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/karamokosidibe701-rgb/DateSenseAI.git
cd DateSenseAI
```

Install the dependency:

```bash
pip install -r requirements.txt
```

Launch the application:

```bash
streamlit run app.py
```
